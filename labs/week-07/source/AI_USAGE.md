# AI_USAGE — LAB 07

บันทึกการใช้ AI ระหว่างทำงาน · **ใช้ AI ได้ แต่ต้องเป็นเจ้าของโค้ดที่ส่ง**

> ผู้สอนจะสุ่มถามจากโค้ดที่ส่ง — ถ้าอธิบายไม่ได้ คะแนนส่วนนั้นจะถูกทบทวน

---

## ครั้งที่ 1

**ถามอะไร**
“server ค้างหน้าโหลดไม่ขึ้น Error Code ใน Terminal แสดง waitng for file change before restarting” และ “เราหยุดการทำงานทั้งหมดก่อนได้มั้ย”

**AI ตอบว่าอย่างไร (สรุปสั้น)**
ตรวจพบว่าโปรเซส API ถูกพักอยู่ แนะนำให้ใช้ `fg` เพื่อทำงานต่อ และใช้ Control + C เพื่อหยุดโปรเซส หากมีงานที่ถูกพักให้ตรวจด้วย `jobs` แล้วใช้ `fg` เรียกกลับก่อนหยุด

**ใช้ส่วนไหน / แก้เองตรงไหน**
รัน `fg` ใน terminal และจัดการปัญหาการทำงานของเซิร์ฟเวอร์จนกลับมาทำงานต่อได้ ไม่ได้แก้โค้ด API ในขั้นตอนนี้

**เข้าใจโค้ดที่ได้มาไหม** [x] เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ


## ครั้งที่ 2

**ถามอะไร**
“ใช้ button ไม่ได้หรอ”, “ขอเป็น Inline CSS ได้มั้ยสั้นๆ ง่ายๆ ขอแค่มันดูสมมาตร” และ “ปุ่มไม่ตรงแล้ไม่ชิดกัน”

**AI ตอบว่าอย่างไร (สรุปสั้น)**
อธิบายการใช้ `button` กับ `useNavigate` และการใช้ `Link` เพื่อไปหน้ารายละเอียด จากนั้นแนะนำให้จัดปุ่มด้วย Inline CSS โดยใช้ `display: flex`, `gap` และ `alignItems`

**ใช้ส่วนไหน / แก้เองตรงไหน**
ทดลองแก้ปุ่มนำทาง และปรับส่วนแสดงผลใน `RequestCard.jsx` ด้วยตนเอง โดยใช้ `Link` ไปหน้ารายละเอียดและจัดปุ่มเปลี่ยนสถานะกับปุ่มลบให้อยู่ใกล้กัน

**เข้าใจโค้ดที่ได้มาไหม** [x] เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

## สรุป

- ส่วนที่เขียนเองทั้งหมด: ส่วนที่ลงมือปรับเองคือฟังก์ชันเปลี่ยนสถานะและการจัดวางปุ่ม ส่วนการจัดการโปรเซสและถ่ายภาพหลักฐานทำตามคำแนะนำด้วยตนเอง
- ส่วนที่ AI ช่วย: อธิบายปัญหาและวิธีแก้ข้างต้น
- ส่วนที่ยังไม่มั่นใจ: ไม่มีส่วนที่ไม่มั่นใจ
