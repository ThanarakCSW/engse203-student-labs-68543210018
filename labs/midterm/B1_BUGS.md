## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) ที่แผงสรุป | SummaryPanel:12 | ไม่มีการเรียกใช้ Prop Key | เรียกใช้ Key ให้ถูกต้อง |
| 2 | ตัวเลข "เสร็จสิ้น" ในแผงสรุปไม่ตรงกับที่เห็นจริง | DashboardPage:50 | มีการใช้ request.status ซ้ำกับ in-progress | แก้ไขจุด request.status ที่ซ้ำให้เป็น completed |
| 3 | กดตัวกรองสถานะใด ๆ แล้วผลไม่เปลี่ยน (เหมือนกรองไม่ทำงาน) | DashboardPage:55 | มีการใช้งานใช้งาน .filter ผิด เพราะรุบุว่าให้ filter แค่ pending จึงทำให้ status อื่นไม่แสดง  | แก้ไขจากการที่กำหนดแค่ pending ให้เป็น filter จากตัวแปร statusFilter ที่เก็บ Status ทั้งหมดไว้ |
| 4 | เปลี่ยน URL `REQ-101` → `REQ-102` แล้วข้อมูลไม่เปลี่ยน | RequestDetailPage:28 | ไม่มีการล้างค่าจาก useEffect ทำให้เมื่อ useEffect ทำงานอีกครั้งจะยังค้างค่าเดิมไว้ | ทำการเพิ่ม requestId และ reloadKey(มีประกาศไว้แต่ไม่ได้ใช้ด้านบน) เพื่อเมื่อ useEffect ทำงานเสร็จและมีค่า requestId เปลี่ยนไปจะทำการเริ่ม useEffect อีกรอบ |
| 5 | กด "ลบ" แล้วการ์ดหาย แต่ตัวเลขในแผงสรุปไม่ลด | DashboardPage:51 | ไม่ได้ใส่ตัวแปรใน Dependency Array ทำให้ค่าใน useMemo ค้างอยู่ค่าเดิม | ทำการเพิ่มตัวแปร request เพื่อทำให้เมื่อ request มีการเปลี่ยนจะทำการใช้ useMemo ใหม่อีกครั้ง |
| 6 | กด "ลบ" แล้วหน้าพัง/ว่างเปล่า | DashboardPage:64 | ไม่มีการใช้ await เพื่อรอการทำงานของคำสั่ง deleteRequest(requestId) | เพิ่ม await เพื่อรอให้คำสั่ง deleteRequest(requestId) ทำงานให้เสร็จก่อนจะทำบรรทัดอื่น |
