Week 11 • Full-Stack Web Application

Campus Service — ระบบรับคำร้องขอใช้บริการ (Full-Stack)

ระบบบูรณาการ 3 ชั้น (Three-Tier Architecture) ทำงานร่วมกันระหว่าง React 18, Express API และฐานข้อมูล SQLite (campus.db) พร้อมรองรับการรันโหมด Production บนพอร์ตเดียว (Single Port)

สถาปัตยกรรมระบบ 3-Tier (React + Express + SQLite)
ผลการตรวจอัตโนมัติ ผ่าน 41 / 41 รายการ (100%)
API Automated Test ผ่าน 8 / 8 ข้อ (100%)
สถานะการ Deploy พร้อมใช้งานจริง (Cloud Deployable)
การใช้งานบน Cloud (Render): ระบบถูกกำหนดค่าผ่าน render.yaml พร้อมรันคำสั่ง npm run build และเปิดบริการด้วย npm start โดยสามารถเข้าถึงหน้าเว็บและ API ได้จากโดเมนเดียวกัน
เปิดใช้งานแอปพลิเคชันบน Render (Live App) ดู Source Code ดูเอกสาร Evidence
